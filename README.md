# Campus Hub 🎟️📡

A responsive single-page campus utility website with:

- 🎟️ **Free Passes**: attendance tracking, free-pass calculations, leave planning, timetable import, holidays, and localStorage persistence.
- 📡 **Room Radar**: room availability by day/time, floor filtering, natural-language room search, live countdowns, AC tagging, and WhatsApp sharing.
- 🌙 **Theme toggle**: light/dark mode.
- 📱 **Responsive design**: works on desktop and mobile.

## Run locally

Open `index.html` in a browser.

No build tools, frameworks, backend, or npm packages are required.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and this `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will publish the site.

Your site will normally be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Important data note

The app stores user-entered attendance/plan data in the browser's `localStorage`. It does not require a database or server.

The sample timetable and holidays are embedded in the page and should be replaced with your institution's real timetable/calendar before using it as an official campus tool.
